# 📊 Retail Sales Performance Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive **Retail Sales Performance Dashboard** developed using **Microsoft Power BI**.

The dashboard transforms retail sales data into meaningful business insights by analyzing sales, profit, customers, products, regions, states and payment methods.

---

## 🎯 Project Objective

The main objective of this project is to analyze retail sales performance and create an interactive dashboard that helps users understand:

- Overall Sales Performance
- Profitability
- Monthly Sales Trends
- Product Category Performance
- Regional Sales Performance
- Customer Segments
- Payment Methods
- Top Performing Products
- State-wise Sales

---

## 📊 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- **Total Sales:** 1.03 Billion
- **Total Profit:** 171.28 Million
- **Total Quantity Sold:** 53,725
- **Total Customers:** 2,970

---

## 📈 Dashboard Features

### 1. Monthly Sales Trend
Analyzes sales performance over time using a line chart.

### 2. Sales by Category
Shows sales performance across different product categories.

### 3. Profit by Category
Compares profit generated by different product categories.

### 4. Sales by Region
Analyzes sales performance across different regions.

### 5. Sales by Customer Segment
Shows sales contribution from different customer segments.

### 6. Top 10 Products by Sales
Identifies the top-performing products based on sales amount.

### 7. Sales by Payment Mode
Shows sales distribution across different payment methods such as UPI, Card, Cash and Wallet.

### 8. Sales by State
Provides geographical analysis of sales using a map.

### 9. Interactive Slicers
The dashboard includes interactive filters for:

- Region
- Category
- Payment Mode

- **Stores**

Relationships were created between the tables to enable interactive analysis.
